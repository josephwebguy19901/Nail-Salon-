# Lilac Lane Nails: demo website

A one-page demo website for a fictional nail salon, built with plain HTML and CSS.

**Built by:** [JosephWebWeaver](https://josephwebweaver.com)

## What it shows
- Responsive layout that works on phones and desktops
- Light and dark mode support
- Simple services and price list
- WhatsApp booking button
- Accessible colors and keyboard focus styles

## Tools
HTML5, CSS3, Google Fonts (Bricolage Grotesque and DM Sans)

## Run it
Open `index.html` in any browser.

## Notes
The business name, prices and content are fictional and made for demonstration only.
